# welcome--js

This is a sandbox project to help learn Git, HTML, CSS, JavaScript.

The page shows cards in a pinterest-like layout, one card per developer. 

* In index.html, add a card with your name and an image similar to the example card.
* Keep your card simple:
    * use an image URL — no image/video files in the repo
    * about as short as the example card, no inline styles
    * if you want to add custom styles to the card, make styles/yourname.css 
* Add a page in `pages/` (e.g. `pages/011_yourname.html` — next free number).
* You can add some JavaScript to your page.

View online: https://cambridge-dev-lab.github.io/welcome--js
